# カード・貴族カタログ

[README](../README.md) / [エンジン仕様](engine_specs.md)

この表は `get_all_cards()` / `get_all_nobles()` の値から作成しています。正本は [card_data.h](../src/card_data.h) と [noble_data.h](../src/noble_data.h) です。カタログ更新時はこの表も照合してください。

色順は **白・青・緑・赤・黒**。カードのコストは割引前の必要トークン数、貴族の要求は購入済みカードのボーナス枚数です。IDはcsplendor内の定義で、外部サービスのIDとは別途対応付けます。

カードは90枚（レベル1: 40、レベル2: 30、レベル3: 20）、貴族は12種類です。金ボーナスのカードはありません。各カードは指定色の永続ボーナスを1つ持ちます。

## プログラムから取得する

```python
import csplendor as cs

cards = [
    {"id": c.id, "level": c.level, "points": c.points,
     "bonus": int(c.bonus), "cost": list(c.cost)}
    for c in cs.get_all_cards()
]
nobles = [
    {"id": n.id, "points": n.points, "requirement": list(n.requirement)}
    for n in cs.get_all_nobles()
]
assert len(cards) == 90 and len(nobles) == 12
```
